Paths

Honest words for the days that are hard to name.

Sixteen paths, each written for a specific kind of stuck. Pick the one that sounds like you. None of them will tell you to just try harder.

For the days the front door feels heavy

Seven tiny steps and honest words for when it is hard to leave the house.

Read this path →

It is never too late to start over

For anyone who feels behind: status follows service, and a late start is still a start.

Read this path →

For the ones who did not get the big title

No college, no scholarship, no family money, no door held open. What comes after.

Read this path →

You do not have to prove you are him

For the mirror-checking, rating-app, comparison crowd. Being known beats being looked at.

Read this path →

Someone else’s ARR is not a verdict on you

For founders refreshing strangers’ numbers at 2am. The scoreboard is curated.

Read this path →

For the one who has never been the pretty one

For the friend who holds the bags. Known, not just noticed.

Read this path →

For the one who was told her value has an expiry date

Worth is not a depreciating asset. Dignity and forward motion, on your terms.

Read this path →

You do not have to announce it to start

For the ones who gained weight and cannot say it out loud. Quiet, private, boring steps.

Read this path →

If the world is too loud, you are not the problem

Plain words for autistic adults: masking, overload, routines, late diagnosis.

Read this path →

For the ones who found a whole world in a fandom

For K-pop and K-drama fans. Keep the fandom; bring some of the devotion home.

Read this path →

Whatever you did, there is a way back

A real turning around gets a real clean slate. You are not too far gone.

Read this path →

When the whole country feels like a fight

For the ones worn down by the news, the group chat and the feed. Care without carrying all of it.

Read this path →

You know it was not what they said

For the ones cast out over something that never happened. Being known by a few beats being believed by a crowd.

Read this path →

For the ones who wanted a crew, a code and a name

For the ones raised on The Godfather and Kamurocho. Loyalty is a virtue. Give it a worthy object.

Read this path →

For the ones who come alive when the drop hits

For the ones who love the scene and the beautiful people in it. The night is good. You are there for more than the night.

Read this path →

You wanted to be wanted. That was never the problem

For the ones whose wanting became the thing they cannot say. Being wanted is not the same as being known.
